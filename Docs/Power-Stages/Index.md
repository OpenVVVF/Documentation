# Power Stages

OpenVVVF power stages are physical chassis/inverter assemblies that pair with the control module. Each chassis is a configurable family with its own ratings, user manual, and step-by-step assembly guide.

- **C1** — Small chassis family (in development).
- **C2** — Mid-size chassis family.
- **C3** — Large chassis family (in development).
