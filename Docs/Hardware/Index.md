# Hardware

OpenVVVF hardware is split into two parts: the reusable control module and the power-stage chassis that it drives.

- [Control Assembly](Control-Assembly/index.html) - the dual-MCU control board that runs the firmware.
- [Power Stages](Power-Stages/index.html) - the physical inverter chassis families (C1, C2, C3).
