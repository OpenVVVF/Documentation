# Assembly Guide

This guide documents the build of the OpenVVVF control module, chapter by chapter, in the order the physical assembly is performed. Chapters are published as each build phase is documented, so this index grows alongside the physical unit.

## Chapters

1. [IO Board Assembly](IOBoard/Index.md) - populate and solder the control module IO board.

2. Main control board population
3. Power board population
4. Control module assembly and test
