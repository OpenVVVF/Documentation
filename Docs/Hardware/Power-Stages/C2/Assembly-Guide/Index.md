# Assembly Guide

This guide documents the build of a Chassis Size 2 inverter, chapter by chapter, in the order the physical assembly is performed. Chapters are published as each build phase is documented, so this index grows alongside the physical unit.

Read the preparation chapter first: it covers the workspace, equipment, and parts verification every chapter depends on.

## Chapters

1. [Preparation](1_Preparation/Index.md) - workspace, equipment, and parts verification before starting.
2. [DC-Link Filter Board](2_DC-Link-Filter-Board/Index.md) - populating and soldering the DC-link filter PCB.
3. [DC-Link Capacitor Board](3_DC-Link-Capacitor-Board/Index.md) - populating and soldering the DC-link capacitor PCB.
4. [IGBT Mounting](4_IGBT-Mounting/Index.md) - mounting the three IGBT half-bridge modules to the heatspreader, including thermal compound application and torque procedure.
5. [IGBT Temperature Sensor Wiring Harness](5_IGBT-Temp-Sense-Harness/Index.md) - building the temperature-sensor harnesses that connect to the control assembly.
6. [IGBT Temperature Sensor Mounting](6_IGBT-Temp-Sense-Mounting/Index.md) - mounting the ring-lug temperature sensors to the heatspreader.
7. [Bottom Stack Assembly](7_Bottom-Stack-Assembly/Index.md) - installing the bottom spacers, DC-link bus bars, filter board, and phase bus bars onto the heatspreader. The finished stack is then set aside.
8. [DC-Link Capacitor Module Assembly](8_DC-Link-Capacitor-Module/Index.md) - assembling the DC-link capacitor module from the populated capacitor board, bus bars, and film capacitors.
9. [DC-Link Capacitor Module Mounting](9_DC-Link-Capacitor-Module-Mounting/Index.md) - mounting the DC-link capacitor module onto the bottom stack and making the bus-bar connections.
10. [Control Assembly Mounting](10_Control-Assembly-Mounting/Index.md) - mounting the assembled control module into the chassis.
11. [Gate Drive Wiring Harness](11_Gate-Drive-Wiring-Harness/Index.md) - building the harness connecting the control assembly to the gate driver board.
12. [Current Sense Wiring Harness](12_Current-Sense-Wiring-Harness/Index.md) - building the harness connecting the phase current sensors to the control assembly.
13. [Final Control Assembly](13_Final-Control-Assembly/Index.md) - completing the control-side wiring and closing out the control assembly.
14. [Review Checks](14_Review-Checks/Index.md) - pre-power review: torque witness marks, polarity, insulation, and workmanship inspection.
15. [Initial Low-Voltage Testing and Calibration](15_Initial-Low-Voltage-Testing/Index.md) - first low-voltage power-up, sensor checks, and calibration.
16. [Outer Shell Mounting](16_Outer-Shell-Mounting/Index.md) - mounting the outer shell onto the assembled power stage.

## Planned build order

The physical build proceeds in roughly this order, and chapters follow it:

1. Preparation - workspace, ESD setup, equipment, and parts verification
2. DC-link filter board (PCB population)
3. DC-link capacitor board (PCB population)
4. IGBT mounting
5. IGBT temperature-sensor wiring harnesses
6. IGBT temperature-sensor mounting
7. Bottom stack assembly: spacers, bus bars, and filter board mounting; then set the stack aside
8. DC-link capacitor module assembly
9. DC-link capacitor module mounting
10. Control assembly mounting
11. Gate-drive wiring harness
12. Current-sense wiring harness
13. Final control assembly
14. Review checks
15. Initial low-voltage testing and calibration
16. Outer shell mounting
